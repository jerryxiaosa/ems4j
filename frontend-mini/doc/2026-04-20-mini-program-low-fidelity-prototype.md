# EMS4J 用户端微信小程序低保真原型

- 文档版本：V1.0
- 创建日期：2026-04-20
- 对应 PRD：`2026-04-20-mini-program-user-prd.md`
- 目的：用于评审页面结构、信息层级、核心交互路径

## 1. 原型说明

本原型为**低保真原型**，只用于确认：

- 页面清单是否完整
- 页面信息层级是否合理
- 页面之间的跳转关系是否清晰
- 关键功能入口是否符合第一期预期

本轮**不讨论**：

- 视觉风格
- 品牌色
- 动效细节
- 技术实现方案

## 2. 整体信息架构

```text
启动
  -> 登录页
    -> 首页（账户正常）
    -> 引导页（未匹配 / 未开户 / 账户异常）

Tab:
  首页 | 充值 | 账单 | 我的

二级页面:
  首页 -> 电表列表页 -> 单表详情页
  账单 -> 账单月列表页 -> 账单日明细页
  充值 -> 支付结果页
  我的 -> 订单页
  订单页 -> 支付结果页（查看结果）
```

## 3. Tab 导航结构


## 6. 核心流程原型
### 6.1 登录流程

```text
登录页
  -> 登录成功
    -> 首页
  -> 登录成功但账户不可正常使用
    -> 引导页
```

### 6.2 充值支付流程

```text
首页/充值 Tab
  -> 充值页
    -> 选择金额
    ->（按需模式先选电表）
    -> 发起支付
    -> 支付结果页
      -> 返回首页
      -> 查看订单
```

### 6.3 账单查看流程

```text
账单 Tab
  -> 账单月列表页
    -> 历史月份按日页
    -> 本月按日页
```

### 6.4 电表查看流程

```text
首页
  -> 电表列表页
    -> 单表详情页
```

## 7. 本轮重点评审项

请优先评审以下内容：

1. Tab 结构是否合理
2. 首页是否足够简洁
3. 充值页的按需/非按需分支是否清楚
4. 账单“月列表 -> 日明细”的两级结构是否合理
5. 电表列表和单表详情的存在是否符合第一期预期
6. 我的页是否过轻或过重
7. 订单入口从 Tab 挪到“我的”是否合理

## 8. 下一步建议

若本低保真原型评审通过，下一步建议：

1. 基于状态版原型继续补充提示文案
2. 输出正式页面原型稿
3. 再进入技术方案与开发计划
