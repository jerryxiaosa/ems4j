## 1. 说明

本文件继续补充第二批核心接口的字段口径，覆盖账单与电表相关页面。

本轮只覆盖以下四类接口：

1. 账单月列表接口
2. 账单日明细接口
3. 电表列表接口
4. 单表详情接口

口径原则与第一批保持一致：

- 不引入通用 `loginState` / `dataState` / `rechargeState` 等泛状态字段
- 业务提示优先通过领域字段或 `tip` 表达
- 页面空态优先通过空列表表达
- 字段只覆盖当前页面所需数据，不预埋后台管理端字段

## 2. 账单月列表接口

### 2.1 用途

用于账单页一级展示月份入口列表。

### 2.2 入参

无业务入参，直接基于当前登录用户获取可查看账单月份。

### 2.3 出参字段

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `list` | `array` | 是 | 月份列表 | 按月份倒序返回 |

### 2.4 `list` 子项字段

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `month` | `string` | 是 | 月份标识 | 建议格式：`yyyy-MM` |
| `monthLabel` | `string` | 是 | 月份展示文案 | 例如：`2026年03月`、`本月` |
| `isCurrentMonth` | `boolean` | 是 | 是否本月 | 用于区分本月入口样式 |
| `hasMonthlySummary` | `boolean` | 是 | 是否有月汇总 | 本月固定为 `false`，历史月通常为 `true` |
| `monthEnergy` | `number` | 否 | 月电量 | 仅历史月份返回 |
| `monthFee` | `number` | 否 | 月电费 | 仅历史月份返回，单位为元 |
| `tip` | `string` | 否 | 提示文案 | 本月可返回：`查看本月已过去日期数据` |

### 2.5 字段说明

- 本月入口需要保留在列表中
- 本月不展示月汇总，因此：
  - `hasMonthlySummary=false`
  - `monthEnergy`、`monthFee` 可为空
- 历史月份通常返回月汇总值
- 若当前用户暂无可查看账单，直接返回 `list: []`

## 3. 账单日明细接口

### 3.1 用途

用于账单页二级展示指定月份下的按日明细。

### 3.2 入参

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `month` | `string` | 是 | 查询月份 | 建议格式：`yyyy-MM` |

### 3.3 出参字段

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `month` | `string` | 是 | 当前月份 | 回显查询月份 |
| `monthLabel` | `string` | 是 | 当前月份展示文案 | 例如：`2026年04月` |
| `tip` | `string` | 否 | 页面提示文案 | 本月可返回：`查看本月数据`；月初可返回：`当月暂无记录` |
| `list` | `array` | 是 | 按日明细列表 | 无数据时返回空数组 |

### 3.4 `list` 子项字段

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `date` | `string` | 是 | 日期 | 建议格式：`MM-dd` 或 `yyyy-MM-dd` |
| `tipEnergy` | `number` | 是 | 尖电量 | 单位建议为 `kWh` |
| `peakEnergy` | `number` | 是 | 峰电量 | 单位建议为 `kWh` |
| `flatEnergy` | `number` | 是 | 平电量 | 单位建议为 `kWh` |
| `valleyEnergy` | `number` | 是 | 谷电量 | 单位建议为 `kWh` |
| `deepValleyEnergy` | `number` | 是 | 深谷电量 | 单位建议为 `kWh` |
| `totalEnergy` | `number` | 是 | 总电量 | 单位建议为 `kWh` |
| `tipFee` | `number` | 是 | 尖电费 | 单位为元 |
| `peakFee` | `number` | 是 | 峰电费 | 单位为元 |
| `flatFee` | `number` | 是 | 平电费 | 单位为元 |
| `valleyFee` | `number` | 是 | 谷电费 | 单位为元 |
| `deepValleyFee` | `number` | 是 | 深谷电费 | 单位为元 |
| `totalFee` | `number` | 是 | 总电费 | 单位为元 |

### 3.5 字段说明

- 历史月份正常返回完整按日数据
- 本月只返回已过去日期的数据
- 月初数据尚未准备好时：
  - `list: []`
  - 返回 `tip`
- 不额外设计 `monthReady` 或 `dataState` 字段

## 4. 电表列表接口

### 4.1 用途

用于电表列表页展示当前账户下的全部电表。

### 4.2 入参

无业务入参，直接基于当前登录用户获取数据。

### 4.3 出参字段

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `list` | `array` | 是 | 电表列表 | 无数据时返回空数组 |

### 4.4 `list` 子项字段

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `meterId` | `string` | 是 | 电表 ID | 用于进入单表详情 |
| `meterName` | `string` | 是 | 电表名称 | 列表主展示文案 |
| `balance` | `number` | 是 | 电表余额 | 单位为元 |
| `isOnline` | `boolean` | 否 | 是否在线 | 用于前端展示在线 / 离线 |

### 4.5 字段说明

- 第一阶段不在电表列表接口返回近七日电量
- 列表页只承载“余额 + 在线状态 + 跳转入口”
- 若当前账户下只有一块表，接口仍按列表返回，由前端决定页面展示
- `isOnline` 比抽象的状态编码更贴近当前业务能力，第一阶段优先使用该字段

## 5. 单表详情接口

### 5.1 用途

用于单表详情页展示单块电表的余额与用电信息。

### 5.2 入参

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `meterId` | `string` | 是 | 电表 ID | 对应电表列表中的 `meterId` |

### 5.3 出参字段

| 字段名 | 类型 | 必填 | 含义 | 说明 |
|---|---|---|---|---|
| `meterId` | `string` | 是 | 电表 ID | 回显当前电表 |
| `meterName` | `string` | 是 | 电表名称 | 页面顶部主标题 |
| `isOnline` | `boolean` | 否 | 是否在线 | 用于前端展示在线 / 离线 |
| `balance` | `number` | 是 | 当前余额 | 单位为元 |
| `tipEnergy` | `number` | 是 | 尖电量 | 单位建议为 `kWh` |
| `peakEnergy` | `number` | 是 | 峰电量 | 单位建议为 `kWh` |
| `flatEnergy` | `number` | 是 | 平电量 | 单位建议为 `kWh` |
| `valleyEnergy` | `number` | 是 | 谷电量 | 单位建议为 `kWh` |
| `deepValleyEnergy` | `number` | 是 | 深谷电量 | 单位建议为 `kWh` |
| `totalEnergy` | `number` | 是 | 总电量 | 单位建议为 `kWh` |

### 5.4 字段说明

- 第一阶段不返回单表电费相关字段
- 第一阶段不返回“最近数据摘要”
- 页面顶部展示重点为：
  - 当前余额
  - 尖峰平谷深谷电量
  - 总电量
- 若后端可稳定提供在线信息，单表详情可同步展示 `isOnline`
