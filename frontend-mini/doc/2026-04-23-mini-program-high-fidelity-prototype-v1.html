页面状态补充

高保真重点展示正常主路径，但页面状态和空态仍然保留在同一份文档里，避免后续只看视觉稿时丢掉流程判断。

首页采用“摘要优先、图表独立兜底”的分层加载方式。
充值页只有正常态和表单态，不再额外设计“不可充值”业务分支。
账单页保留本月无记录、历史月可查看、列表异常等关键状态说明。

首页状态

正常态

展示账户名称、共 X 个电表、当前余额、去充值，以及近七日电量/电费切换图表。

加载态

账户名称、余额和图表都显示骨架或占位信息；图表区域可独立加载，不阻塞顶部账户卡片渲染。

空数据态

余额正常展示，图表区域提示“暂无近七日数据”，不影响继续充值或进入账单、电表页面。

异常态

首页摘要接口失败时展示整页重试；仅图表接口失败时，只在图表卡片内提示失败并支持重新加载。

充值与支付状态

非按需模式

直接展示账户名称、当前余额和自定义金额输入，点击“去支付”进入确认支付页。

按需模式

先通过下拉框选择电表，再展示当前电表余额和金额输入；未选电表前，主按钮保持不可点击。

金额异常态

当金额为 0、空值或非法格式时，仅做表单级提示，并禁用“去支付”按钮。

确认支付页

展示充值金额、到账金额、服务费，用户点击“立即支付”后再拉起微信支付。

记录与账单状态

充值缴费记录

支持正常态、空数据态、加载态和异常态；列表页支持上一页/下一页等分页操作。

账单月列表

账单 Tab 默认进入月列表页，本月保留入口但不展示月汇总；历史月份展示月电量和月电费汇总。

本月按日页

只展示已过去日期的数据；若当月暂无任何记录，则显示“当月暂无记录”空态，不额外附带说明文字。

账单日明细页

单日卡片分成“电量明细”和“电费明细”两组，并提供“月初 / 月末”快速跳转，减少长列表查找成本。

电表状态

电表列表页

展示账户下电表余额和在线状态；支持正常态、单电表态、空数据态和异常态。

单表详情页

重点展示在线状态、当前余额、尖峰平谷深谷电量和总电量；不再承载电费或最近数据摘要。

说明

核心流程原型

流程说明继续贴在高保真文档里，方便评审时同时判断页面跳转和返回路径，不需要再单独翻低保真。

一级 Tab 页面只保留居中标题；二级页面统一采用“左返回 + 居中标题”。
支付结果页返回统一回到充值缴费页，不按来源分流。
账单日明细返回到账单月列表页，单表详情返回到电表列表页。

登录流程

标准路径 登录页 -> 登录成功 -> 首页
受限路径 登录页 -> 登录成功但账户不可正常使用 -> 引导页

充值支付流程

充值主路径 首页 / 充值 Tab -> 充值缴费页 ->（按需模式先选电表） -> 确认支付页 -> 发起微信支付 -> 支付结果页
记录入口 充值缴费页 -> 充值缴费记录 我的页 -> 充值缴费记录

账单查看流程

账单主路径 账单 Tab -> 账单月列表页 -> 历史月份按日页 / 本月按日页
我的页快捷入口 我的页 -> 账单记录 -> 直接切换到账单 Tab 首页

电表查看流程

首页入口 首页 -> 共 X 个电表 > -> 电表列表页 -> 单表详情页
